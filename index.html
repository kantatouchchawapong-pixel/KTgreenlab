KT Green Hub คืออะไร?

ศูนย์ข้อมูลสิ่งแวดล้อมประเทศไทย

KT Green Hub พัฒนาขึ้นเพื่อรวบรวมข้อมูลและแหล่งความรู้ด้านสิ่งแวดล้อม ช่วยให้ประชาชนเข้าถึงข้อมูลได้ง่ายขึ้น ข้อมูลแต่ละประเภทอาจมาจากผู้ให้บริการภายนอก จึงควรตรวจสอบแหล่งที่มาและเวลาที่อัปเดตก่อนนำไปใช้อ้างอิง

🌦️ แผนที่อากาศและพยากรณ์ประเทศไทย

สำรวจสภาพอากาศรายจังหวัด พร้อมเรดาร์ฝนและแนวโน้มล่วงหน้า 7 วัน

แผนที่เรดาร์แสดงภาพฝนจากผู้ให้บริการภายนอก ส่วนจุดจังหวัดและค่าพยากรณ์มาจากแบบจำลองอากาศ ไม่ใช่เครื่องตรวจวัดภาคพื้นดิน

💧 Water Watch

ระบบตรวจสอบแหล่งข้อมูลด้านน้ำ

กดปุ่มตรวจสอบระบบ เพื่อทดสอบว่าแหล่งข้อมูลที่ตั้งค่าไว้ตอบกลับหรือไม่

สถานะการเชื่อมต่อ

ส่วนนี้ยังอยู่ระหว่างตรวจสอบความถูกต้องของ API และข้อมูลสถานี

ยังไม่ได้ตรวจสอบ
คำเตือน: การเชื่อมต่อ API สำเร็จไม่ได้แปลว่ามีข้อมูลระดับน้ำที่ผ่านการตรวจสอบแล้ว เว็บไซต์จะไม่แสดงตัวเลขระดับน้ำจนกว่าจะยืนยันชื่อสถานี หน่วยวัด และเวลาที่ตรวจวัดได้

ระบบจะดึงข่าวทั้งหมดก่อน แล้วกรองตามหมวดหมู่และคำค้นหาภายในเว็บไซต์

🌱 ศูนย์ความรู้สิ่งแวดล้อม

เลือกหัวข้อที่สนใจเพื่อเริ่มเรียนรู้

🗑️

การจัดการขยะ

เรียนรู้การแยกขยะ ขยะทั่วไป ขยะอันตราย และการลดขยะในชีวิตประจำวัน

♻️

การรีไซเคิล

ทำความเข้าใจการนำวัสดุกลับมาใช้ใหม่และการคัดแยกวัสดุรีไซเคิล

💧

น้ำและมลพิษ

เรียนรู้เรื่องคุณภาพน้ำ แหล่งกำเนิดมลพิษ และการอนุรักษ์แหล่งน้ำ

🌫️

คุณภาพอากาศ

ทำความเข้าใจฝุ่น PM2.5 มลพิษทางอากาศ และผลกระทบต่อสิ่งแวดล้อม

🌳

ป่าไม้และสัตว์ป่า

เรียนรู้ระบบนิเวศ ความหลากหลายทางชีวภาพ และการอนุรักษ์ธรรมชาติ

🌍

สภาพภูมิอากาศ

เรียนรู้ภาวะโลกร้อน ก๊าซเรือนกระจก และการเปลี่ยนแปลงสภาพภูมิอากาศ

เนื้อหาในหน้านี้เป็นความรู้ทั่วไป ไม่ใช้แทนประกาศเตือนภัยหรือคำแนะนำจากหน่วยงานภาครัฐ

♻️ เครื่องมือสิ่งแวดล้อม

เริ่มต้นใช้งาน KT Green Hub

1
เลือกเมนูที่ต้องการ

ใช้แถบเมนูด้านบน หรือเลือกการ์ดจากหน้าแรก

2
เลือกพื้นที่หรือหมวดหมู่

ในหน้าสภาพอากาศให้เลือกจังหวัด ส่วนหน้าข่าวให้เลือกหมวดหมู่ที่สนใจ

3
กดปุ่มค้นหาหรือแสดงข้อมูล

รอระบบเชื่อมต่อและแสดงผลบนหน้าจอ

4
ตรวจสอบแหล่งที่มาของข้อมูล

ข้อมูลจากผู้ให้บริการภายนอกอาจมีเวลาล่าช้า ควรตรวจสอบวันเวลาและแหล่งอ้างอิง

คำถามที่พบบ่อย

ข้อมูลอัปเดตแบบเรียลไทม์หรือไม่?

ขึ้นอยู่กับแหล่งข้อมูล สภาพอากาศเป็นข้อมูลแบบจำลองและพยากรณ์ ข่าวขึ้นอยู่กับเวลาที่แหล่งข่าวเผยแพร่ และข้อมูลน้ำต้องตรวจสอบ API กับสถานีจริงก่อน

ทำไมบางครั้งข้อมูลไม่แสดง?

อาจเกิดจากอินเทอร์เน็ต ผู้ให้บริการ API ไม่ตอบสนอง หรือระบบต้นทางขัดข้อง ลองกดรีเฟรชอีกครั้ง

ข้อมูลที่บันทึกไว้ถูกส่งไปที่ไหน?

ภารกิจ Eco Challenge เก็บไว้ในเบราว์เซอร์ของอุปกรณ์นั้น ไม่ใช่ฐานข้อมูลกลาง
